Laporan Kegiatan Program PPG

Catat kelompok, kegiatan, sasaran usia, waktu pelaksanaan, dan dokumentasi foto — lalu ekspor jadi PDF siap laporan.

1Nama Bidang

Bidang/unit yang melaksanakan atau bertanggung jawab atas kegiatan ini.

2Nama Kelompok

Tambahkan satu atau lebih kelompok yang mengikuti kegiatan.

3Nama Kegiatan

Tambahkan satu atau lebih kegiatan yang dilaksanakan.

4Jenis Usia Pelaksana

Pilih satu atau lebih kelompok usia yang melaksanakan kegiatan.

5Tanggal Pelaksanaan

Tanggal, bulan, dan tahun kegiatan dilaksanakan.

6Foto Kegiatan

Unggah dokumentasi foto kegiatan (bisa lebih dari satu).

📷 Ketuk untuk memilih foto kegiatan

Riwayat Laporan

💾 Lokal

Ketuk PDF untuk mengekspor ulang, atau Hapus untuk menghapus laporan.

Sinkronisasi Firebase

Hubungkan ke Firebase Realtime Database agar laporan tersimpan online dan bisa diakses dari perangkat lain. Kosongkan & simpan untuk kembali memakai penyimpanan lokal saja.

Cara Menghubungkan

1. Buat project di console.firebase.google.com, aktifkan Realtime Database.

2. Salin Database URL project ke kolom di atas.

3. Atur Rules agar aplikasi bisa membaca/menulis, misalnya (mode uji coba):

{
  "rules": {
    "laporan_ppg": {
      ".read": true,
      ".write": true
    }
  }
}

Untuk keamanan lebih baik, ganti aturan ini dengan otentikasi/secret setelah pengujian selesai.
